# CI, live, next to your code

- **Runs view**: runs of this repository with their jobs and steps, updating while they run. The pull request of your branch sits on top with all its checks.
- **Status bar**: ✓ / ✖ / ● for every check of the commit you have checked out. Click it to open the run.
- **Filters**: only your runs, only failures, one workflow, or only this branch.
